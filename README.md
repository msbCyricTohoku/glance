# GLANCE(1)                          User Commands                         GLANCE(1)

## NAME
    glance - a high-performance directory listener

## SYNOPSIS
    glance [DIRECTORY]

## DESCRIPTION
    GLANCE is a minimalist alternative of 'ls' command.

## INSTALLATION
    $ make

## HOWTO
    $ ./glance
    $ ./glance ~/
    $ ./glance ~/ h     (shows hidden files)
